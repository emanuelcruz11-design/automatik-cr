# AUTOMATIK CR V7 — Flujo guiado de restaurante

- El Centro Demo ahora indica que la prueba inicia en **Ver todos los QR**.
- El usuario elige la mesa que desea simular. En PC escanea el QR y en móvil toca **Probar mesa**.
- Se agregó navegación **← Volver** en QR, Cliente, Cocina y Administración.
- Cocina solo puede avanzar: Recibido → En preparación → Listo → Entregado.
- **Pagado ya no puede ejecutarse desde Cocina.**
- Después de Entregado, Cocina muestra **Esperando pago del cliente**.
- El pago se simula exclusivamente desde la vista Cliente.
- Cliente muestra una explicación y el botón **Pagar como cliente y generar factura**.
- Administración aclara que es un panel de consulta y refleja el pago/factura una vez realizado por Cliente.
- Se reforzó la guía paso a paso del recorrido completo.
- Se corrigió el cálculo visual de duración para evitar valores incorrectos de 1440 minutos.
